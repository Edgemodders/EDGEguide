# EDGE<span class="y">guide</span> docs

EDGEguide lets Claude Code show a modder how the EDGE tools work, in the editor itself: it opens the right view, selects the item, points at the button and runs the tool's own command while the modder watches. An Edgemodders extension for [EDGEkit](https://github.com/Edgemodders/EDGEkit) and VS Code, used through [EDGEchat](https://github.com/Edgemodders/EDGEchat), the EDGE plugin for Claude Code.

| Document | What it covers |
|---|---|
| [Design](design.html) | What EDGEguide is and is not, the facts it rests on, the tools, the contract with the EDGE extensions, phases G0 to G4 and the G0 questions |
